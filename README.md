# Velox Plugins

Public plugin marketplace for Velox EDI.

## Marketplace

ChatGPT workspace admins can import this repository as a plugin marketplace.

- Source: `https://github.com/VeloxEDI/velox-plugins`
- Path: leave blank
- Branch: `main`

The marketplace manifest is `.agents/plugins/marketplace.json`.

## Plugins

### Velox Config

Understand existing Velox configuration and create new importable Velox `.CFG` files. GitHub is used only as a read-only source of shared Velox documentation and, optionally, one designated customer configuration repository.
